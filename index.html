Projetos

Reabilita360

Esta API backend foi desenvolvida para uma aplicação de reabilitação fisioterapêutica voltada ao público idoso. O sistema utiliza técnicas de visão computacional para acompanhar a execução dos exercícios em tempo real via câmera, garantindo maior precisão e suporte ao tratamento.

O projeto teve origem no meu 5º período da faculdade no contexto de um projeto de extensão universitária, surgindo da união entre engenharia de software e tecnologia assistiva aplicada à saúde.

Nesta iniciativa, atuei na liderança da equipe de estudantes e na condução técnica do desenvolvimento. Fui responsável pela definição da arquitetura do backend, modelagem do banco de dados e estabelecimento das convenções e boas práticas de código do projeto.

Stack técnica:

  • Fastify + TypeScript
  • Prisma ORM + PostgreSQL
  • Autenticação via JWT
  • Validação de dados com Zod

BioVox

Este projeto foi desenvolvido durante o 6º período de graduação com o objetivo de promover a inclusão comunicativa de pessoas diagnosticadas com doenças neuromusculares degenerativas. A proposta consiste em um sistema capaz de interpretar o sopro do paciente como sinal de entrada primário, viabilizando a expressão de necessidades básicas e a interação com o ambiente.

A partir do processamento desses estímulos de ar, o dispositivo converte os sinais captados em frases estruturadas de comunicação e em comandos direcionados à automação residencial. A solução utiliza como base o microcontrolador ESP32, garantindo o processamento em tempo real e a portabilidade necessária para o uso cotidiano do paciente.

Minha contribuição no desenvolvimento abrangeu a concepção e estruturação da lógica de funcionamento do dispositivo, além do desenvolvimento do firmware. Fui responsável pela codificação embarcada no ESP32, cobrindo desde a leitura e filtragem dos sinais do sensor até o processamento responsável por traduzir os sopros nas ações correspondentes.

Stack técnica:

  • ESP32 + KY-038
  • Linguagem C++ com as bibliotecas...
  • Aplicativo em React-Native
